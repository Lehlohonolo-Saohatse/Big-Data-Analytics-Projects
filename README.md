## Overview

This repository contains my project work for the **Big Data Analytics Techniques (ITBDA4)** module.

The module focuses on applying data analytics and Big Data techniques to analyse datasets, identify patterns, generate insights, and support data-driven decision-making.

The coursework covers the use of **R programming, exploratory data analysis, statistical analysis, data mining, machine learning techniques, time-series analysis, text analysis, Hadoop, SQL, PostgreSQL, and in-database analytics**.

The repository brings together the practical work completed across the module and serves as both an academic submission repository and a portfolio of applied Big Data Analytics skills.
